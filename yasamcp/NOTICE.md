# Third-Party Open Source Notices

yasamcp uses the following third-party open source tools at runtime (all MIT licensed). Thanks to their contributors:

- **codegraph** — code structure analysis engine
  - Repo: https://github.com/colbymchenry/codegraph
- **ripgrep** — high-performance recursive search tool
  - Repo: https://github.com/BurntSushi/ripgrep
